Explainer style (big numbers, serif captions)

Stat card text: LABEL|VALUE|SUB LINE|TAG. Make the number count with FROM>TO, e.g. PEOPLE ON EARTH|8,000,000,000>4,167,999,994|7 SECONDS LATER|TIME-LAPSE 2.5x. Timers work too: 2:14>0:00. Question title, Italic caption, Watermark and Subtitle plate use the text box. Smoke plume is in Scene changes.
Text box: CCTV = camera name (CAM 07), Face scan = status word (NOT IDENTIFIED), Glow title = use | for a new line. Stack cues at the same time to combine looks, e.g. CCTV + Face scan + Caption.
